#  Base Plate Design

##  Purpose
The base plate acts as the **foundation of the robot**, supporting:
- Motors  
- Tendon routing  
- Limit switch integration  
- Connection to the lead screw  

---

##  Iterations
### Version 1
- Motors mounted externally  
- Limited routing provisions  

### Version 2 (Final)
- Motors integrated directly onto the base plate  
- Increased dimensions to accommodate components  
- Additional holes for:
  - Limit switches  
  - Vinyl tube routing  
  - Structural mounting  

---

##  Design Features
- Motor mounting holes aligned to specifications  
- Routing paths for tendons and vinyl tubes  
- Interface for lead screw connection  
- Structural support for entire robot assembly  

---

##  Challenges
- Tolerance issues required iterative redesign  
- Minor post-processing (filing/drilling) used for fitting
